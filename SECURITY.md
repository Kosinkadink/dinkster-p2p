# Security policy

Security fixes target the current main branch. Include the affected version or
commit, operating system, relevant configuration, impact, and minimal
reproduction steps in your report. Do not include credentials or private data.

Report suspected vulnerabilities privately through
[GitHub security advisories](https://github.com/Kosinkadink/dinkster-p2p/security/advisories/new),
not a public issue. Ordinary bugs belong in this repository's issue tracker.

The sidecar's IPC authentication, filesystem containment, digest validation,
lease authorization, and network-scope restrictions are security boundaries.
Third-party dependencies have their own licenses and security policies.
